# 1597 3.0
- (formally MLauncher)
- A Mac application launcher, fully coded in Python 3
- Suported ONLY on Mac (Windows Edition Coming Soon!)
# Features
- Run Mac apps (Finder, Music, Mail, and Notes)
- Play Exclusive Games!
- Run Example Code
# How To Use
1. Install Python 3.0 or newer
2. Double Click Software.py
3. Click 'Run' on the Status Bar
